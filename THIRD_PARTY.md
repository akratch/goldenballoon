## n64-fast3d-engine binary-redistribution condition

The n64-fast3d-engine license (full text in `platform/fast3d/PROVENANCE.md`)
permits binary redistribution only when "the binary contains no assets you do
not have the right to distribute". This repository's shipped binaries and the
web build load a user-supplied ROM at runtime and never bundle ROM-derived
assets — see `tools/check_no_rom.sh` (shipped-artifact guard) and
`tools/check_clean_room.sh` (repository-history guard), both of which run in
CI (`.github/workflows/correctness.yml`).
