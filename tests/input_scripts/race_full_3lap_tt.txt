# DKR regression fixture -- a FULL 3-lap TIME TRIAL on Ancient Lake, driven to
# the finish, through the post-race result screens, to the EEPROM record write.
#
# Use with MDKR_AUTOPILOT=1. This is the P3.1 route: it is the only fixture that
# reaches the code which writes a course/lap record to EEPROM, because DKR only
# records times when Time Trial is ON (objects.c race_finish_time_trial, gated on
# gIsTimeTrial). nav_to_time_trial_race.txt / race_full_3lap.txt confirm
# Time Trial OFF ("Tracks" mode) and therefore can never save a time.
#
# Navigation is nav_to_time_trial_race.txt plus ONE extra input: at the
# track-select Time-Trial stage (trackmenu gMenuStage == 1) the stick must be
# pushed DOWN to move gTracksMenuTimeTrialHighlightIndex 0 -> 1, so that
# set_time_trial_enabled(1) runs (menu.c:9844). Without that DOWN the race is a
# normal 8-racer Tracks race.
#
# Driving is left to MDKR_AUTOPILOT (DKR's own AI pathing); no throttle input is
# needed or wanted -- the post-race menus are EDGE-detected, so a held A would
# produce a single press and then nothing.
#
# Measured landmarks (deterministic): level_load at frame ~2641, lap 1 at clock
# ~1592, lap 2 at ~3170, lap 3 (finish) at clock 4777 / frame ~7587. The A taps
# below start after that and walk the post-race sequence:
#   POSTRACE_STAGE_BEGIN -> SHRINK_VIEWPORT -> RACE_TIMES -> ENTER_INITIALS
#   (3 characters + confirm) -> RACE_RECORDS -> OPTIONS -> END, where
#   mark_to_write_flap_times()/mark_to_write_course_times() run and the next
#   input_update() flushes the records to EEPROM.
#
# Budget: 13000 frames.
