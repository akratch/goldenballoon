## Resource trace mechanism

`MDKR_RESOURCE_STATS=1` (or `MDKR_TRACE=1`) enables
`mdkr_resource_trace_enabled()` (`platform/platform_sdl_min.c:243-253`,
`platform/mdkr_trace.h:12`). On each level generation the renderer emits
(`platform/fast3d/gfx_pc_dkr.c:2565-2608`):

- `renderer_generation: level=.. players=.. cutscene=.. texStart=.. texCreated=.. texDeleted=.. texLive=.. texPeak=.. shaderCreates=..`
  — texture object counts; `texPeak` is the per-generation high-water.
- `registry_state: level=.. players=.. cutscene=.. live=.. high=.. ambiguous=.. fullFails=.. maxProbe=..`
  — gfx pointer-registry occupancy; `high` is its high-water.

`players` is stored as N-1 (so `players=3` = four local humans). All runs were
headless and muted (`MDKR_AUDIO=0`, `--headless-frames`).

**NOT RUN / not emitted, with reason:**
- `[RESOURCE-HEARTBEAT]` lines were **not emitted** — that heartbeat is gated on
  the live GL swap loop (`s_glReady`, `platform_sdl_min.c:3474-3490`), which the
  headless path does not enter. Blocker: headless has no GL present loop; the
  per-generation `renderer_generation`/`registry_state` lines above carry the
  same texture/registry high-water and were captured instead.
- The `renderer_generation` **delta** line for the *last* level in a run is
  flushed only when the *next* generation begins, so the 1P hub (its terminal
  level) has no `renderer_generation` delta; its `registry_state` and the
  run-wide `texPeak` are recorded instead. The race levels are followed by the
  results/return generation, so their race `renderer_generation` line is present.

## Exact commands

The three existing headless routes (1P hub route from
`tests/check_adventure_hub.py`; 3P/4P race scripts from
`tests/check_race_multiplayer.py`), each with `MDKR_RESOURCE_STATS=1` added and
frame dumping omitted. Env isolated per run (`env -i` + private
`MDKR_SAVE_DIR`/`MDKR_VIDEO_CONFIG_PATH` to keep the frame-indexed input scripts
on the hermetic Original clock, exactly as those checks do). Commands:

```sh
# (i) 1P Adventure hub visit — Timber's Island (levelId 0)
MDKR_AUDIO=0 MDKR_PRESENT_RATE=original MDKR_SIMULATION_CADENCE=enhanced \
MDKR_SYNTH_FIELDS=1 MDKR_TRACE=1 MDKR_RESOURCE_STATS=1 \
MDKR_DRIVE_ROUTE="<HUB_TOUR_ROUTE from check_adventure_hub.py>" MDKR_AUTOPILOT=1 \
MDKR_SAVE_DIR=<tmp>/save MDKR_VIDEO_CONFIG_PATH=<tmp>/save/video.ini \
  build-census/mdkr64 --headless-frames 12000 \
    --input-script tests/input_scripts/adventure_hub_drive.txt \
    --rom baserom.us.v80.z64

# (ii) 3P / 4P Tracks race — Ancient Lake (levelId 5)
MDKR_AUDIO=0 MDKR_SIMULATION_CADENCE=enhanced MDKR_SYNTH_FIELDS=1 MDKR_TRACE=1 \
MDKR_RESOURCE_STATS=1 MDKR_AUTOPILOT=1 MDKR_AUTOPILOT_UNSTICK=1 MDKR_ORACLE_STATE=1 \
MDKR_SAVE_DIR=<tmp>/save MDKR_VIDEO_CONFIG_PATH=<tmp>/save/mdkr64.ini \
  build-census/mdkr64 --headless-frames 9600 --window-size 640x480 \
    --input-script tests/input_scripts/race_{3,4}p_split.txt \
    --rom baserom.us.v80.z64
```
