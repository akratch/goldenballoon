# Multiplayer evidence ledgers

Create one dated record per achievement from these required fields: commit and
clean/dirty provenance; build/protocol/ROM ids; commands; OS/browser/device and
network profile; positive and broken-direction results; accessibility/physical
review; latency/memory/quota/currency measurements; known failures; reviewer;
and final `GO`, expiring `CONDITIONAL GO`, or `STOP`.

Planned ledgers are `session.md`, `phone-party.md`, `rollback.md` and
`online-beta.md`. Until a ledger contains its complete signed matrix, the live
[status](../../multiplayer/STATUS.md) must not show the achievement as done.
