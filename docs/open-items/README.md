# Open items

Every defect this port has hit, with its mechanism, the measurement that found it,
the fix, and the check that would catch a regression. Sections are in reverse
chronological order by wave — newest first — and **nothing is deleted when it is
fixed**: a closed entry is the only warning the next person gets that the same trap
exists. Retractions are recorded in place rather than removed.

Most of these bugs were **silent**. Read the entry for a subsystem before changing
it.
