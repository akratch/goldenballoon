# public_text_denylist.txt -- the single source of truth for the text classes
# that must never reach a public surface.
#
# Consumers read this file at run time:
#   - tools/check_public_surface.py scans committed/staged/outgoing Git blobs
#     and commit messages with Python regexes;
#   - tools/manual/check_github_launch_ready.sh scans GitHub metadata with jq/Oniguruma.
#
# Format: one regex alternative per line. Blank lines, and lines whose first
# non-blank character is #, are ignored. Both engines must accept every line, so
# each line must stay inside their common subset: bracket expressions ([(]) in
# place of backslash escapes, POSIX classes ([[:space:]]) in place of \s, no
# lookaround, no named groups, no backreferences. The GitHub consumer matches
# case-insensitively and the history consumer matches case-sensitively, so a
# pattern must not depend on case to stay narrow.
#
# This file carries the marker text verbatim as its job, so the surface guard
# exempts this exact path. No directory-wide content exemption exists.

# Private paths, internal-only working documentation, and pre-public backup
# remote naming. The prepublic-remote alternative requires a concrete timestamp
# (8 date digits + 6 time digits) so it matches a leaked remote name but not the
# shell template that generates a fresh timestamp on each run.
