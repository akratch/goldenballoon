**Golden Balloon is an unofficial fan project — a decompilation-based native source
port, created for research, preservation and educational purposes. It is not

## This repository contains no game data

No ROM. No textures, audio, music, sequences, models, fonts, sprites or level
geometry. None in the working tree and none in git history. It contains only the
compiled engine, the launcher shell, and project brand art.

To play you must supply your own copy of the original game, legally owned and
dumped by you. It is read **client-side in your browser** and is never uploaded,
transmitted, or stored on any server — this is a static site with no backend.

Publication is gated on an automated check (`tools/check_no_rom.sh` in the source
repository) that scans every shipped file for N64 ROM header magic in all three
byte orders, and fails closed. That is a mechanism, not a promise.
