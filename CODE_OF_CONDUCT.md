# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its code of
conduct. The canonical text is authoritative:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## The short version

Contributors, maintainers and participants pledge to make participation in this
project a harassment-free experience for everyone, regardless of age, body size,
visible or invisible disability, ethnicity, sex characteristics, gender identity and
expression, level of experience, education, socio-economic status, nationality,
personal appearance, race, caste, colour, religion, or sexual identity and
orientation.

Expected: empathy and kindness, respect for differing opinions and experience,
graceful acceptance of constructive feedback, taking responsibility for mistakes and
learning from them, and prioritising what is best for the community over what is
best for you individually.

Unacceptable: sexualised language or imagery and unwelcome sexual attention;
trolling, insulting or derogatory comments, and personal or political attacks; public
or private harassment; publishing others' private information without permission;
and any other conduct which could reasonably be considered inappropriate in a
professional setting.

## Scope

This applies within all project spaces — the repository, issues, pull requests and
discussions — and also when an individual is officially representing the project in
public spaces.

## Enforcement

Report unacceptable behaviour to the maintainers via a private security advisory or
by contacting the repository owner directly. All complaints will be reviewed and
investigated promptly and fairly. Maintainers are obligated to respect the privacy
and security of the reporter of any incident.

Maintainers who do not follow or enforce this code of conduct in good faith may face
temporary or permanent repercussions as determined by other members of the project's
leadership.

Enforcement follows the Contributor Covenant's four-tier ladder — correction,
warning, temporary ban, permanent ban — as described in the
[full text][cc] under "Enforcement Guidelines".

## A note specific to this project

Technical disagreement is welcome and expected; this project settles it with evidence
rather than seniority. "Show me the measurement" is a normal and collegial request
here, not an accusation — see [CONTRIBUTING.md](CONTRIBUTING.md). Insisting on
evidence is in scope. Being unpleasant while doing it is not.
